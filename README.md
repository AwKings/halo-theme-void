# VOID for Halo · 使用指南

[Typecho-Theme-VOID](https://github.com/AlanDecode/Typecho-Theme-VOID) 的 Halo 2 移植版：双栏瀑布流首页、沉浸式头图、极简排版。

- 仓库：<https://github.com/AwKings/halo-theme-void>
- 说明与更新记录：<https://blog.sanmizu.com/archives/halo-theme-void>
- 原主题作者：熊猫小A（<https://blog.imalan.cn>）；移植：awking
- 运行要求：Halo `>= 2.20`

本文只讲怎么用；功能清单、与原版的实现差异见上面那篇文章。

---

## 快速上手

四步跑起来：

1. **装主题** —— 后台上传 `theme-void.zip` → [一、安装与升级](#一安装与升级)
2. **填三处必填** —— 站点名、首页大标题、小标题 → [二、设置项](#二设置项)
3. **关掉 shiki 的主题侧渲染** —— 否则代码块的行号与 Fira Code 不生效 → [四、写文章 → 代码块](#代码块)
4. **（可选）装 `plugin-void`** —— 相册、提示块、注音、友链靠它解析 → [六、配套插件](#六配套插件)

## 一、安装与升级

**安装**

- 后台上传：控制台「主题 → 安装主题」，选 `theme-void.zip`，装完点「启用」
- 放目录：主题文件夹放到 `~/.halo2/themes/theme-void`，重启 Halo

**升级**

主题已存在时不能用「安装」（会提示已存在）。到「主题 → 主题详情 → 升级」上传新 zip 即可，已有设置会保留。

**改完文件不生效**

Thymeleaf 有模板缓存，改模板或样式后执行一次：

```
PUT /apis/api.console.halo.run/v1alpha1/themes/theme-void/invalidate-cache
```

静态资源地址带 `?v=主题版本号`，改版本号浏览器才会重新拉取。

## 二、设置项

四组都在「主题 → 设置」里。**最少要填**：左上角站点名、首页顶部大标题、小标题。头图不填就不显示头图，其余不受影响。

### 基础设置

| 项 | 说明 |
| --- | --- |
| 左上角站点名 | 导航栏左侧文字，留空用站点标题 |
| 首页与归档页顶部大图 | 图片地址或随机图 API，留空不显示头图 |
| 首页顶部大标题 / 小标题 | 留空分别使用站点标题、副标题 |
| 主题颜色模式 | 自动（按下方时间段切换）/ 日间 / 夜间 |
| 首页版式 | 双栏瀑布流 或 单栏 |
| 页脚补充内容 | 支持 HTML，常用于备案号 |
| 打赏二维码 | 图片地址，一张，留空不显示打赏入口 |
| 显示文章点赞按钮 | 用 Halo 内核 upvote 统计，不需要插件 |

### 内容与排版

| 项 | 说明 |
| --- | --- |
| 正文使用衬线体 | 思源宋体，来自 Google Fonts |
| 图片懒加载 | 默认开启 |
| 启用数学公式解析 | 额外加载 MathJax，体积较大，不用就别开 |
| 默认字号 | 14 / 16 / 18 / 20 / 22px，访客可在设置面板自行调节 |
| 代码使用 Fira Code 字体 | 从 Google Fonts 加载 |
| Mac 风格代码块 | 顶部圆点与标题栏 |
| 代码块行号 | Prism line-numbers 生成 |
| 显示图片题注 | 用图片 `alt` 作为题注 |
| X（Twitter）用户名 / 微博昵称 | 分享时 @ 的账号 |
| 评论区提示语 | 显示在评论框上方 |

### 高级设置

| 项 | 说明 |
| --- | --- |
| 桌面端 / 移动端头图高度 | 单位 vh |
| 导航栏模式 | 随滚动显隐 / 固定 / 不固定 |
| 跟随系统深色模式 | 开启后优先跟随系统，忽略上面的颜色模式 |
| 夜间模式开始 / 结束时间 | 24 小时制，支持半小时粒度 |
| 模糊懒加载 | 仅对又拍云、七牛云 CDN 图片生效 |
| 浏览器原生懒加载 | 使用 `loading="lazy"` |
| 品牌字体地址 / 样式 / 字重 | 站点标题的自定义字体（ttf/woff/woff2） |
| 自定义 Service Worker | 填文件名，文件需自行放在站点根目录 |
| 侧边栏社交链接 | 名称 / voidicon 图标名 / 链接 / 打开方式，最多 10 项 |

### SEO

| 项 | 说明 |
| --- | --- |
| 输出 canonical 与社交分享标签 | 若已由 SEO 插件提供请关闭，避免重复 |
| 输出文章结构化数据 | 输出 JSON-LD `BlogPosting`，前台无变化 |

## 三、导航栏

```
[站点名]   主菜单项  分类▾        [搜索框]      🔍  ⚙
```

- **站点名** 在左，「基础设置 → 左上角站点名」可覆盖，留空用站点标题
- **主菜单** 取自 Halo「主菜单」，菜单项有子项时自动渲染为下拉
- **分类** 下拉列出全部文章分类
- 桌面端显示内联搜索框，窄屏收起为搜索图标，点击在导航栏下方展开输入框
- 齿轮打开设置面板（字号 ±、衬线/非衬线切换）
- 头部模式由「高级设置 → 导航栏模式」控制：随滚动显隐 / 固定 / 不固定
- 移动端收进抽屉：站点名 + 汉堡按钮，分类与主菜单在抽屉内平铺

## 四、写文章

### 文章设置

文章编辑页右侧「文章设置」里的字段：

| 字段 | 取值 | 说明 |
| --- | --- | --- |
| 自定义摘要 | 文本 | 覆盖自动摘要，用于首页卡片与分享描述 |
| 文章主图 | 图片地址 | 文章页顶部大图，留空使用文章封面 |
| 文章主图样式 | 顶部显示 / 模糊背景 / 不显示 | 模糊用于亮色图片压字 |
| 首页主图样式 | 不显示 / 标题上方 / 作为标题背景 | 作为背景时加暗色遮罩，建议仅用于暗色图 |
| 在首页显示完整内容 | 是 / 否 | 适合短文章，卡片直接展开正文 |
| 文章目录 | 显示 / 不显示 | 关闭后不渲染目录按钮 |

页面（单页）另有「页面主图」「页面主图样式」两项。

### 扩展语法

以下语法由 `plugin-void` 在服务端解析，Markdown 与富文本编辑器都能直接写；代码块内的同名标记不会被解析。

**图片排版（相册）**

```
[photos]
![](1.jpg)
![](2.jpg)
![](3.jpg)
[/photos]
```

解析为 justified 相册：同一行高度一致、两端对齐、宽度按宽高比分配，桌面端基准 `--ar × 200px`、移动端 `--ar × 120px`。插件会探测每张图的原始宽高（本地图片读文件头，远程图片取一次 HTTP 头并缓存），点击任意一张打开 fancybox 灯箱，同组可左右切换。探测失败时退回等宽等高裁切，不会破版。

普通图片会自动包成 `<figure>` 并支持灯箱，不需要额外标记。

**提示块**

```
[notice]这里是一段需要强调的内容。[/notice]
```

渲染为左侧黄色竖线 + 浅色底。漏写 `[/notice]` 时会解析到本段结尾。

**注音**

```
{{漢字:かんじ}}
```

渲染为 `<ruby>漢字<rt>かんじ</rt></ruby>`。

**友链列表**

```
[links]
[站点名称](https://example.com)+(https://example.com/avatar.png)
[/links]
```

渲染为卡片网格，整卡可点击。

**标题锚点**

正文 `h2`–`h6` 自动补 `id="toc_N"`，文章目录靠它跳转，不用手写。

### 代码块

三个开关（「内容与排版」里）分别控制字体、Mac 风格、行号，都依赖主题自己渲染代码块（Prism 客户端高亮）。

- **Fira Code**：带编程连字
- **Mac 风格**：32px 顶部留白 + 红黄绿圆点 + 标题栏（标题栏显示语言名）
- **行号**：没有 `language-*` 类的代码块同样显示
- **复制按钮**：右上角，桌面悬停淡入、触屏常显，复制纯代码文本（不含行号），成功后短暂显示「已复制」。无需开关。

**语言标注**：高亮依赖 `language-*` 类。用 Markdown 编辑器写 ```` ```cpp ```` 会自动带上；富文本编辑器里插入的代码块若没选语言则不着色（行号、Mac 风格、复制仍正常）。

**和 shiki 插件冲突**：装了 `shiki` 且开着「启用主题侧渲染」时，代码块会被它接管并渲染进 shadow DOM，主题的行号与 Fira Code 都会失效（Mac 风格只剩简化版）。到该插件设置里关掉这一项即可。

## 五、页面、路由与模板

| 路径 | 模板 | 说明 |
| --- | --- | --- |
| `/` | `index.html` | 首页，瀑布流或单栏 |
| `/archives` | `archives.html` | 按年份归档，带折叠与标签云，使用「首页与归档页顶部大图」 |
| `/categories`、`/tags` | `categories.html`、`tags.html` | 分类/标签总览 |
| `/categories/{slug}`、`/tags/{slug}` | `category.html`、`tag.html` | 单个分类/标签的文章列表 |
| `/authors/{name}` | `author.html` | 作者页 |
| `/search?keyword=xxx` | `search.html` | 站内搜索 |
| `/archives/{slug}` | `post.html` | 文章页 |

站内搜索是**前端检索**：拉取公开文章接口（最多 200 篇）后在浏览器里按标题、摘要、正文匹配。文章超过 200 篇时，较早的文章搜不到。

### 自定义模板

| 模板 | 适用 | 效果 |
| --- | --- | --- |
| Landscape | 文章 | 巨大标题、巨幅图片的沉浸式排版 |
| 归档 | 页面 | 按年份归档 + 标签云，适合单独做一个时间线页面 |

在编辑器右上角的模板选择器里切换。

## 七、常见问题

**代码块没有样式、行号或字体不对**
shiki 等插件开着「主题侧渲染」，关掉它。

**`[photos]`、`[notice]` 原样显示**
没装 `plugin-void`，或插件未启用。

**改了模板/样式没反应**
清模板缓存（见「一、安装与升级」）；仍不生效就改主题版本号，强制刷新 `?v=` 资源地址。

**相册排版不整齐**
图片宽高探测失败（远程图片不可访问，或响应头里没有尺寸），退回等宽等高裁切。把图片放到本站或可访问的图床即可。

**头图 / 主图不显示**
检查「基础设置 → 首页与归档页顶部大图」和文章的「文章主图 / 封面」是否为可访问的图片地址；「文章主图样式」选「不显示」时文章页不会渲染主图。

**首页打开 500，文章页正常**
某篇文章的摘要里含 `<` 之类的字符。主题已按纯文本输出摘要，若仍出现请检查是否有插件改写了摘要。

## 八、给二次开发者

- 静态资源只能放 `templates/assets/**`，放 `assets/**` 会 404
- 设置项在 `settings.yaml`，文章/页面注解表单在 `annotations.yaml`
- 文章卡片是 `partials/post-card.html`，整体布局与头图在 `partials/layout.html`
- 改完模板执行 `PUT /apis/api.console.halo.run/v1alpha1/themes/theme-void/invalidate-cache`
