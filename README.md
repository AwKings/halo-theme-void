# VOID for Halo

[Typecho-Theme-VOID](https://github.com/AlanDecode/Typecho-Theme-VOID) 的 Halo 2 移植版：双栏瀑布流首页、沉浸式头图、极简排版。

- 原主题作者：熊猫小A（[blog.imalan.cn](https://blog.imalan.cn)）
- 移植：awking
- 移植说明与更新记录：[blog.sanmizu.com/archives/halo-theme-void](https://blog.sanmizu.com/archives/halo-theme-void)
- 要求 Halo `>= 2.20`，插件端需 Halo `>= 2.20`

## 特性

- 首页双栏瀑布流（Masonry），可切换单栏
- 沉浸式头图：首页/归档页大图、文章主图，支持模糊与「作为标题背景」
- 深色模式：日间 / 夜间 / 按时间段自动（默认 22:00–06:59），可跟随系统
- 文章目录（tocbot）、字数统计、文章点赞（ENJOY）
- 代码块：Prism 高亮、Mac 风格标题栏、行号、Fira Code、一键复制
- 分享：X、微博、QQ、微信扫码、复制链接
- 归档（按年份折叠 + 标签云）、分类、标签、作者页、站内搜索
- 设置面板（导航栏齿轮）：字号调节、衬线/非衬线切换
- 移动端：抽屉式导航、单栏列表、触屏常显的代码复制按钮

## 快速开始

### 1. 安装

Halo 后台「主题 → 安装主题」上传 `theme-void.zip`，或把主题目录放到 `~/.halo2/themes/theme-void` 后重启。

### 2. 必填设置

「主题 → 设置 → 基础设置」至少填 **左上角站点名**（留空则用站点标题）与 **首页顶部大标题/小标题**；头图不填则不显示，页面直接从头图下方的第一屏开始。

### 3. 关掉 shiki 的主题侧渲染（重要）

如果装了 `shiki` 插件并且开着「启用主题侧渲染」，代码块会被它接管并渲染进 shadow DOM，主题的 **行号、Fira Code、Mac 风格** 都会失效。请到该插件设置里关闭这一项，交给主题自带的 Prism 处理。

### 4. 可选：配套插件

| 插件 | 作用 |
| --- | --- |
| [plugin-void](https://github.com/AwKings/halo-plugin-void) | 解析本文档里的扩展语法（相册、提示块、注音、友链）；点赞与评论赞踩按 IP 去重并记录互动明细 |
| [plugin-bangumi](https://github.com/AwKings/halo-plugin-bangumi) | 追番/收藏/日历短代码，用于 Bangumi 页面 |

不装 `plugin-void` 时主题仍可正常使用，只是 `[photos]` 等标记会原样输出。

## 导航栏

沿用原版 VOID 的头部布局：

```
[站点名]   主菜单项  分类▾        [搜索框]      🔍  ⚙
```

- **站点名** 在左，「基础设置 → 左上角站点名」可覆盖，留空用站点标题
- **主菜单** 取自 Halo「主菜单」，菜单项有子项时自动渲染为下拉
- **分类** 下拉列出全部文章分类
- 桌面端显示内联搜索框，窄屏收起为搜索图标，点击在导航栏下方展开输入框
- 齿轮打开设置面板（字号 ±、衬线/非衬线切换）
- 头部模式由「高级设置 → 导航栏模式」控制：随滚动显隐 / 固定 / 不固定
- 移动端收进抽屉：站点名 + 汉堡按钮，分类与主菜单在抽屉内平铺

> 参照初之音头部（站点名 + 首页 + 主菜单 + 分类▾ + 更多▾ + 仅图标搜索）的版本在 `void_sanmizu` 分支，样式由 `void-sanmizu.css` 覆盖，并多一个「导航栏『更多』菜单」设置项。

## 代码块

三个开关（内容与排版）分别控制字体、Mac 风格、行号，都依赖主题自己渲染代码块（Prism 客户端高亮）。若被 shiki 等插件接管，效果见「快速开始 → 3」。

- **Fira Code**：`body.firaCode` 类驱动 `.yue` 下的 `pre`/`code`/`tt`/`kbd`/`samp`，带编程连字
- **Mac 风格**：给 `pre` 加 32px 顶部留白 + 红黄绿圆点 + 标题栏（标题栏显示语言名）
- **行号**：Prism `line-numbers` 插件，没有 `language-*` 类的代码块同样显示行号
- **复制按钮**：右上角，桌面悬停淡入、触屏常显，复制纯代码文本（不含行号），成功后按钮短暂变为「已复制」。Mac 风格开启时按钮位于标题栏内。无需开关。

代码高亮依赖 `language-*` 类：用 Markdown 编辑器写 ```` ```cpp ```` 会自动带上；富文本编辑器的代码块若未选语言则不着色（但行号、Mac 风格、复制仍正常）。

## 写文章

### 文章设置

文章编辑页右侧「文章设置」中的字段（由主题的 `annotations.yaml` 提供）：

| 字段 | 取值 | 说明 |
| --- | --- | --- |
| 自定义摘要 | 文本 | 覆盖自动摘要，用于首页卡片与分享描述 |
| 文章主图 | 图片地址 | 文章页顶部大图，留空使用文章封面 |
| 文章主图样式 | 顶部显示 / 模糊背景 / 不显示 | 模糊效果用于亮色图片压字 |
| 首页主图样式 | 不显示 / 标题上方 / 作为标题背景 | 作为背景时会加暗色遮罩，建议仅用于暗色图 |
| 在首页显示完整内容 | 是 / 否 | 适合短文章，卡片直接展开正文 |
| 文章目录 | 显示 / 不显示 | 关闭后不渲染目录按钮 |

页面（单页）另有「页面主图」「页面主图样式」两项。

### 扩展语法

以下语法由 `plugin-void` 在服务端解析，Markdown 与富文本编辑器都可以直接写，代码块内的同名标记不会被解析。

**图片排版（相册）**

```
[photos]
![](1.jpg)
![](2.jpg)
![](3.jpg)
[/photos]
```

解析为 `.photos` 相册：插件探测每张图的原始宽高（本地图片读文件头、远程图片取一次 HTTP 头并缓存），据此实现 justified 排版——同一行高度一致、两端对齐、宽度按宽高比分配，桌面端基准 `--ar × 200px`、移动端 `--ar × 120px`，点击任意一张打开 fancybox 灯箱（同组可左右切换）。探测失败时退回等宽等高裁切，不会破版。

普通图片会自动包成 `<figure>` 并支持灯箱，不需要额外标记。

**提示块**

```
[notice]这里是一段需要强调的内容。[/notice]
```

渲染为左侧黄色竖线 + 浅色底。漏写 `[/notice]` 时会解析到本段结尾。

**注音**

```
{{漢字:かんじ}}
```

渲染为 `<ruby>漢字<rt>かんじ</rt></ruby>`。

**友链列表**

```
[links]
[站点名称](https://example.com)+(https://example.com/avatar.png)
[/links]
```

渲染为卡片网格，整卡可点击。

**标题锚点**

正文 `h2`–`h6` 自动补 `id="toc_N"`，文章目录依赖它跳转，无需手写。

## 页面与路由

| 路径 | 模板 | 说明 |
| --- | --- | --- |
| `/` | `index.html` | 首页，瀑布流或单栏 |
| `/archives` | `archives.html` | 按年份归档，带折叠与标签云，使用「首页与归档页顶部大图」 |
| `/categories`、`/tags` | `categories.html`、`tags.html` | 分类/标签总览 |
| `/categories/{slug}`、`/tags/{slug}` | `category.html`、`tag.html` | 单个分类/标签的文章列表 |
| `/authors/{name}` | `author.html` | 作者页 |
| `/search?keyword=xxx` | `search.html` | 站内搜索 |
| `/archives/{slug}` | `post.html` | 文章页 |

站内搜索是**前端检索**：拉取公开文章接口（最多 200 篇）后在浏览器里按标题、摘要、正文匹配，站点文章超过 200 篇时较旧的文章搜不到。

## 自定义模板

| 模板 | 适用 | 效果 |
| --- | --- | --- |
| Landscape | 文章 | 巨大标题、巨幅图片的沉浸式排版 |
| 归档 | 页面 | 按年份归档 + 标签云，适合单独做一个 `/timeline` 之类页面 |

在编辑器右上角的模板选择器里切换。注意「文章设置」里没有「文章类型」字段，Landscape 只能通过模板选择器启用。

## 与原版的差异

- PHP 模板逻辑改为 Halo Finder API（`postFinder`、`categoryFinder`、`tagFinder`、`menuFinder`）
- 原配套插件移植为 `plugin-void`：文章点赞、评论赞踩（按 IP 去重）、访客互动记录、扩展语法解析
- 浏览量用 Halo 内核 `post.stats.visit`；字数统计改为前端计算
- 评论使用 Halo 官方评论组件；评论赞踩按钮尚未注入该组件（其 Lit + 多层 shadow DOM 结构），插件接口已就绪
- 原版「图片宽高」由插件在上传时拼进图片地址，本版改为**渲染时探测**（`ImageSizeProbe`），效果一致
- OwO 表情、文章归档短代码未移植
- 搜索改为前端检索（见上文 200 篇上限）
- 静态资源统一放在 `templates/assets/`（Halo 2.22 的资源路由要求）

## 常见问题

**代码块没有样式、行号或字体不对**
shiki 等插件开着「主题侧渲染」。关掉它。

**`[photos]`、`[notice]` 原样显示**
没装 `plugin-void`，或插件未启用。

**改了模板/样式没反应**
Thymeleaf 缓存。改完执行 `PUT /apis/api.console.halo.run/v1alpha1/themes/theme-void/invalidate-cache`，或重启 Halo。资源 URL 带 `?v=主题版本号`，改版本号可强制刷新浏览器缓存。

**相册排版不整齐**
图片宽高探测失败（远程图片不可访问、或返回的头信息里没有尺寸），此时退回等宽等高裁切。把图片放到本站或可访问的图床即可。

**头图/主图不显示**
检查「基础设置 → 首页与归档页顶部大图」与文章的「文章主图 / 封面」是否填了可访问的图片地址；「文章主图样式」选「不显示」时文章页不会渲染主图。

## 目录结构

```
theme.yaml           主题元数据（版本、自定义模板、许可证）
settings.yaml        后台设置项定义（四个分组）
annotations.yaml     文章/页面的注解表单
templates/
  index.html post.html page.html archives.html
  categories.html category.html tags.html tag.html author.html search.html
  post_landscape.html page_archives.html
  partials/  layout.html header.html footer.html post-card.html pagination.html
  assets/    css/ js/ libs/ fonts/ img/
```

二次开发注意两点：静态资源只能放 `templates/assets/**`（放 `assets/**` 会 404）；改完模板记得清缓存。
